# Бот контента

Каждый день добавляет в приложение **1 новые обои** и **1–2 открытки**
(две — в четверг, к пятнице, и за 10 дней до праздника). Запускается бесплатно
на GitHub Actions утром по Бишкеку (в 08:17, запасной запуск в 11:43).

## Откуда берутся картинки

- **Обои** — фото Кыргызстана с [Wikimedia Commons](https://commons.wikimedia.org):
  сначала отобранные сообществом «качественные изображения», потом пейзажи.
  Лицензии свободные (CC BY / CC BY-SA / CC0), но автора указывать обязательно —
  приложение показывает его под картинкой, нажатие открывает страницу фото.
  Фото с узнаваемыми людьми пропускаются: для коммерческого приложения нужно их согласие.
- **Открытки** бот рисует сам: фото с [Openverse](https://openverse.org) только с лицензией
  CC0 / public domain (никаких условий) + поздравление на кыргызском или русском.
  Тексты и поводы — в `texts.py`, оформление — в `cards.py`.

Pinterest и другие сайты, где картинки принадлежат авторам, не используются: за это
Google Play удаляет приложения по жалобам правообладателей.

## Настройка (один раз)

1. **Ключ Firebase.** Firebase Console → ⚙ Project settings → Service accounts →
   Generate new private key. Скачается JSON-файл. Никому его не отправляй и не клади в репозиторий.
2. **Секрет на GitHub.** Репозиторий → Settings → Secrets and variables → Actions →
   New repository secret: имя `FIREBASE_SERVICE_ACCOUNT`, значение — всё содержимое JSON-файла.
3. **Первичное наполнение открытками.** Actions → Daily content → Run workflow:
   command `seed-cards`, count `30`.
4. Дальше всё идёт само каждый день. Запустить вручную: Run workflow с command `daily`.

## Запуск на компьютере

```
cd content_bot
pip install -r requirements.txt
python bot.py daily --dry-run              # ничего не загружает, кладёт картинки в out/
python bot.py seed-cards --count 30        # загрузить в Firebase (нужен ключ, см. ниже)
```

Для загрузки с компьютера укажи путь к ключу:
`set GOOGLE_APPLICATION_CREDENTIALS=C:\путь\к\ключу.json` (Windows).

## Как это устроено

- Файлы кладутся в Storage в папку категории (`nature/`, `cards/`…), документы —
  в одноимённые коллекции Firestore с полями `url`, `urlSmall`, `type`, `tags`, `author`,
  `license`, `sourceUrl`, `createdAt`.
- Имена начинаются с `0auto-<обратное время>`, поэтому в категориях приложения
  новые картинки оказываются первыми, даже у пользователей старой версии.
- Использованные источники запоминаются в документе `bot/state`, повторов не будет.
- Запасов хватит надолго: около 360 отобранных фото и 1100 пейзажей на Commons.
